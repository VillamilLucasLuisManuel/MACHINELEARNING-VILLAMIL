Información del identificador

Esta PWA utiliza un modelo de clasificación de imágenes entrenado con Teachable Machine.

🎯

Objetivo

Identificar si una fotografía corresponde a Luis y rechazar imágenes que no alcancen el nivel de confianza necesario.

🧠

Cómo se entrenó

El modelo aprendió con dos clases: Luis y No Luis, usando ejemplos variados de rostros, grupos, pantallas y otros contenidos.

📊

Interpretación

El porcentaje es una confianza del clasificador, no una prueba absoluta de identidad. Por eso la aplicación aplica un umbral antes de confirmar.

🔒

Uso responsable

Utiliza imágenes con autorización y evita emplear este resultado como único método para decisiones importantes o de seguridad.

Qué hacer si el resultado es incorrecto

  1. Comprueba que el rostro aparezca con buena iluminación.
  2. Prueba una fotografía diferente y que no se haya usado durante el entrenamiento.
  3. Si el error se repite, agrega ejemplos representativos a la clase correspondiente y vuelve a exportar el modelo.

Limitación importante

El clasificador analiza la imagen completa. En una fotografía grupal puede confundirse si los rostros son pequeños o si el encuadre es muy distinto a los ejemplos de entrenamiento.
