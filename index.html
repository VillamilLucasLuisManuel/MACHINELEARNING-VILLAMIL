PROYECTO DE MACHINE LEARNING

¿Esta fotografía es de Luis?

Sube una imagen y consulta el resultado de un modelo entrenado con Teachable Machine.

Probar el identificador

Problemática

En el CBTIS 260 se desea identificar fotografías mediante Machine Learning para determinar si una fotografía de un alumno corresponde o no a una persona específica, en este caso Luis.

Justificación

La verificación de identidad a partir de fotografías se realiza hoy de forma manual, lo que consume tiempo y depende del criterio de cada persona. Automatizar esta tarea con inteligencia artificial resulta importante por las siguientes razones:

  • Control de identidad: permite comprobar con rapidez y de forma consistente si una imagen corresponde a la persona esperada.
  • Automatización y ahorro de tiempo: reduce la revisión manual de fotografías en trámites escolares.
  • Apoyo a la credencialización y a la seguridad escolar: es un primer paso hacia procesos de registro y acceso más confiables.
  • Aprendizaje de IA aplicada: los estudiantes conocen el ciclo completo de un proyecto de Machine Learning, desde el entrenamiento del modelo hasta su uso en una aplicación real.

Objetivo general

Desarrollar una aplicación web progresiva (PWA) que utilice un modelo de clasificación de imágenes para identificar si una fotografía corresponde a Luis, mostrando el resultado y su porcentaje de confianza.

Cómo funciona

  1. 📷

    Elige una imagen

    Sube una fotografía o activa la cámara.

  2. 🧠

    El modelo la analiza

    La red neuronal compara la imagen con lo aprendido en su entrenamiento.

  3. ✅

    Recibe el resultado

    Verás si es Luis o no, con una confianza orientativa.
